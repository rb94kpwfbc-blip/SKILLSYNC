# SkillSync

SkillSync is an interactive educational and tutoring app built with SwiftUI.

## Features

- Interactive periodic table
- Information about all 118 elements
- Element categories and real-world uses
- Progress tracking
- Animated learning interface
- Science lessons

## Built With

- Swift
- SwiftUI
- Xcode

## Status

SkillSync is currently under development.
