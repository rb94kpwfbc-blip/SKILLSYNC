# Element Survival Game Design

## Player

The player is a student using SkillSync. The student controls a robot explorer
that travels through different environments, gathers materials, learns their
properties, and uses that knowledge to survive.

## Repeated Player Actions

The main gameplay loop is:

1. Explore the map.
2. Find and collect materials.
3. Examine the elements or substances that make up those materials.
4. Answer short questions or review clues about their properties.
5. Choose materials for a crafting recipe.
6. Craft equipment.
7. Use that equipment to overcome hazards and enemies.
8. Discover new recipes and continue exploring.

The player repeatedly collects materials, learns what they do, and experiments
with different crafting combinations.

## Goal

The main goal of the first run is to collect iron and carbon, understand why
they are useful together, and craft a steel sword. The player then uses the
sword to reach and defeat the final boss.

Future levels can introduce additional materials, recipes, environments, and
bosses.

## Winning and Surviving

The player wins the first adventure by:

- Collecting the required materials.
- Correctly identifying useful material properties.
- Crafting the steel sword.
- Surviving the environment and enemy encounters.
- Defeating the final boss.

Knowledge should improve the player's chance of survival. A student who
understands the materials can select a better recipe, craft stronger equipment,
and recognize which tool is useful for a particular challenge.

## Failure and the End of a Run

A run ends when the robot's health or energy reaches zero during an
environmental hazard or boss battle.

Failure should support learning instead of removing all progress. After a run
ends:

- The player returns to the latest checkpoint.
- Collected materials from the current unfinished section may be lost.
- Previously discovered element facts and recipes remain unlocked.
- The game explains which material choice, crafting decision, or unanswered
  question could have helped.
- The player can review that information and try the section again.

This gives failure a consequence while encouraging the student to learn and
retry.

## Learning Connection

Element and material knowledge affects crafting by helping the player
understand which substances can be combined and what properties the resulting
material may have.

For example, iron and carbon can be used to represent the creation of steel.
Steel is not a brand-new element. It is an iron-based alloy whose behavior can
change depending on its carbon content and how it is processed. This
distinction can become an important learning moment in the game:

- An **element** contains one type of atom.
- A **compound** contains elements chemically bonded in fixed proportions.
- An **alloy** is a mixture containing a metal and one or more other elements.
- Combining materials does not normally create a new element.

The crafting system can ask the student to use properties such as hardness,
conductivity, reactivity, melting point, density, and state of matter when
choosing a recipe.

## Reasons to Play Again

Players are encouraged to replay when the game contains multiple discoverable
crafting combinations. A new run could allow the player to:

- Discover a recipe they missed.
- Create a different weapon, tool, or armor set.
- Test how different materials affect an item's properties.
- Unlock a different route through the map.
- Answer new randomized learning questions.
- Improve their completion score or boss-fight result.
- Fill a material and recipe collection.
- Encounter a different challenge that rewards another material choice.

Replayability should come from experimentation and discovery, not simply
repeating the same collection steps.
